# Frontera de importación

Reservada para parsers y validación de archivos de etapa 02. En etapa 01 no se
aceptan archivos ni se interpretan encabezados. Los esquemas del dominio validan
estructuras; no son un parser Moodle ni resuelven afiliaciones. Los futuros
adaptadores conservarán el valor original y producirán incidencias explícitas.
